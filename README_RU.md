# croco

Крошечный асинхронный рантайм для Си **без зависимостей** (zero-dependency) в одном заголовочном файле (`croco.h`).

Croco приносит конкурентность в стиле Go в чистый Си: легковесные корутины (грин-треды), буферизированные CSP-каналы и неблокирующий сетевой ввод-вывод — всё это меньше чем в **400 строках кода**.

[English version (README.md)](README.md)

---

## :zap: Почему Croco?

- **Zero Dependencies (Никаких сторонних библиотек)**: Нужен только стандартный libc и системные вызовы ядра Linux. Никаких `libuv`, `libevent`, `pthreads` или внешних пакетов.
- **Single Header**: Просто закиньте `croco.h` в проект и объявите `#define CROCO_IMPLEMENTATION` в одном файле `.c`.
- **Go-стиль в Си**: Запускайте задачи через `croco_go`, синхронизируйте их через типизированные каналы (`chan_send` / `chan_recv`), и пишите асинхронный сетевой код, который читается как простой синхронный.
- **0% CPU в простое**: Работает на системном `epoll`. Когда все задачи спят или ждут сеть, поток честно засыпает в ядре — никакой холостой нагрузки на процессор.

## :warning: Поддерживаемые платформы

> [!WARNING]
> **Croco работает на Linux под `x86_64` и `aarch64` (ARM64 / Raspberry Pi / AWS Graviton / Docker на Apple Silicon).**  
> Он **НЕ** будет работать на Windows или macOS.
> 
> - Ассемблерные вставки для переключения контекста реализованы под **x86_64** и **AArch64**.
> - Движок I/O завязан напрямую на специфичные для Linux вызовы **`epoll`** и **`accept4`**.

## :book: Шпаргалка по базовому API

### 1. Корутины и запуск
```c
// Запуск новой корутины
Context *croco_go(void (*coro)(void *arg), void *arg);

// Уступить квант времени планировщику / другим задачам
void croco_yield(void);

// Запуск event loop (работает, пока не завершатся все живые корутины)
void run_event_loop(void);
```

### 2. Таймеры
```c
// Заснуть на N миллисекунд (интегрировано в epoll; 0% CPU во время сна)
void sleep_ms(uint64_t ms);
```

### 3. Каналы (Синхронизация CSP)
```c
// Создать буферизированный канал на N элементов
Channel *ch = chan_create(capacity);

// Отправить / принять (автоматически уступает управление, если буфер полон / пуст)
chan_send(ch, (void *)val);
void *val = chan_recv(ch);
```

### 4. Неблокирующий ввод-вывод (Сеть и Терминал)
```c
// Перевести сокет или stdin терминала в неблокирующий режим
croco_set_nonblocking(fd);

// Асинхронно ждать готовности дескриптора (EPOLLIN / EPOLLOUT)
void croco_poll(int fd, uint32_t events);

// Чтение / запись / accept (автоматически засыпают на EAGAIN / EWOULDBLOCK)
ssize_t croco_read(int fd, void *buf, size_t count);
ssize_t croco_write(int fd, void *buf, size_t count);
int     croco_accept(int listener_fd, struct sockaddr *addr, socklen_t *addrlen);
```

## :speech_balloon: Примеры: Асинхронный Чат (Examples)

В папке [`examples/`](examples/) находится полноценный интерактивный TCP-чат, демонстрирующий совместную работу корутин, сетевых сокетов и асинхронного ввода с клавиатуры:
* [`examples/server.c`](examples/server.c) — чат-сервер с рассылкой сообщений (broadcast) всем участникам.
* [`examples/client.c`](examples/client.c) — интерактивный консольный клиент.

### Сборка
```bash
make
```
Команда соберет исполняемые файлы `./server` и `./client`.

### Запуск в нескольких терминалах
1. **Терминал 1 (Сервер):**
   ```bash
   ./server
   ```
2. **Терминал 2 (Клиент 1):**
   ```bash
   ./client
   ```
3. **Терминал 3 (Клиент 2):**
   ```bash
   ./client
   ```

Пишите сообщения и жмите Enter. Входящие сообщения из сети и ввод с клавиатуры (`stdin`) опрашиваются параллельно в одном потоке через `epoll`, не блокируя друг друга.

Также к серверу можно подключиться стандартным netcat:
```bash
nc 127.0.0.1 9090
```
